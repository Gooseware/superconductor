- **`LibSQLDatabaseManager`**: Shared singleton across notebook-store (FTS5 fallback) and quorum-fsm (state persistence). Build in Phase 0 shared-infra task.
- **`AbstractGate`**: Base class in superconductor-core for PreflightGate, SignOffGate, QuorumValidator. Standardises check execution, audit logging, typed error throwing.
- **`InMemoryLibSQLClient`** + **`MockNotebookProvider`** + **`TestTokenSigner`**: Shared test infra — build alongside Phase 1 to unblock Phase 2 tests.
- **Phases 1 & 2 parallelisable** once INotebookProvider interface is locked.
- **3-note limit scope**: Per MCP invocation (single `notebook_write` tool call), enforced at schema level.
- **Reviewer token**: `reviewer_session_id` field in quorum-state.json. `notebook_write` MCP accepts optional `reviewer_token` param for `quorum`/`style` note authority check.
- **Pre-commit signing key**: `SHA-256({session_id}:{track_id}:{oracle_verdict_timestamp})` generated by SignOffGate, stored in quorum-state.json. Pre-commit hook reads and verifies independently.
